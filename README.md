# Native Balance Tracker

Tracks native coin balances like ETH/BNB/POL/AVAX/XPL across Ethereum, BNB Chain, Base, Arbitrum, Optimism, Polygon, Avalanche, Scroll, zkSync Era, Linea, Gnosis, Abstract, Plasma, and Robinhood Chain with USD values. It runs entirely in the browser: only public addresses are needed, never private keys, and the wallet list is stored in the browser's localStorage.
