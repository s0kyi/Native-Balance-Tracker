# Native Balance Tracker

Tracks native coin balances like ETH/BNB/POL/AVAX/XPL across Ethereum, BNB Chain, Base, Arbitrum, Optimism, Polygon, Avalanche, Scroll, zkSync Era, Linea, Gnosis, Abstract, Plasma, Robinhood Chain, HyperEVM (Hyperliquid), Monad, and X Layer with USD values. Chains are colour-coded and can be dragged to reorder, and wallets can be sorted high-to-low by any column. It runs entirely in the browser: only public addresses are needed, never private keys, and the wallet list is stored in the browser's localStorage.
